# PRAfolio

The living creative universe of Pratham Chhabra — a professional portfolio built with a custom WebGL2 shader environment, numbers-based navigation, and a content architecture ready for future admin management.

## Tech Stack

- Vite + React + TypeScript
- Custom WebGL2 shaders (no 3D library dependency)
- Tailwind CSS
- Lucide React icons

## Structure

- `src/three/` — Living Creative Universe (WebGL2 shader + interaction state machine)
- `src/components/` — Navigation, Sections, ProjectCaseStudy
- `src/data/content.ts` — All content (separated from presentation)
- `src/router.tsx` — Hash-based router with case study support
